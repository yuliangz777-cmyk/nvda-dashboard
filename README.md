# NVDA Intelligence Dashboard

NVDA 專屬追蹤網站，包含：

- TradingView 即時互動圖表
- NVIDIA 財報與年度營收趨勢
- Data Center、Gaming、Pro Visualization、Automotive、Robotics 產品線
- 從晶片設計到雲端客戶的 AI 供應鏈地圖
- 催化劑、風險、技術面檢核與本機投資筆記

## GitHub Pages

專案為純靜態網站，不需建置。將儲存庫的 Pages 來源設為 `main` branch / root 後即可發布。

## 資料原則

財報數字應優先使用 NVIDIA Investor Relations 與 SEC filings。行情圖表由 TradingView 提供。網站內容僅供研究，不構成投資建議。
